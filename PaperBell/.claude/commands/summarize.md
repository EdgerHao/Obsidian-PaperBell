# Summarize Command

Summarize academic papers, literature notes, or selected text to extract key insights.

## Usage Examples

```
/summarize
/summarize [[Paper Title]]
/summarize -f Inputs/Zotero/paper.md
```

## Features

- Extract key findings from research papers
- Summarize methodology and conclusions
- Identify important citations and references
- Generate concise summaries for literature reviews

## Options

- `-f, --file` - Specify a file to summarize
- `-l, --length` - Summary length (short/medium/long)
- `-k, --keywords` - Extract key keywords
