# Outline Command

Generate structured outlines for academic papers, research proposals, and reports.

## Usage Examples

```
/outline
/outline My Research Paper
/outline -t research-proposal "Climate Change Impacts"
```

## Features

- Generate IMRaD-style paper outlines
- Create research proposal structures
- Build literature review outlines
- Customize outline depth and sections

## Options

- `-t, --type` - Outline type (paper/proposal/review)
- `-d, --depth` - Number of outline levels (default: 3)
- `-s, --sections` - Custom sections to include

## Outline Templates

### Research Paper (IMRaD)
1. Introduction
2. Methods
3. Results
4. Discussion
5. Conclusion

### Research Proposal
1. Background & Literature Review
2. Research Questions
3. Methodology
4. Expected Outcomes
5. Timeline
